BEFORE YOU START:
✓ Download all files from the project folder
✓ Have GitHub & Render accounts ready
✓ Get Telegram Bot Token (@BotFather)
✓ Have Facebook email & password

================================================================================
STEP 1: SETUP GITHUB REPOSITORY
================================================================================

1. Create new GitHub repository named: facebook-tracker-bot
2. Clone to your computer:
   git clone https://github.com/YOUR_USERNAME/facebook-tracker-bot.git
   cd facebook-tracker-bot

3. Place all downloaded files in this folder:
   - app/main.py
   - requirements.txt
   - .env.example
   - .gitignore
   - Procfile
   - README.md
   - RENDER_SETUP_BANGLA.md

4. Push to GitHub:
   git add .
   git commit -m "Facebook tracker bot - initial"
   git push origin main

================================================================================
STEP 2: GET TELEGRAM BOT TOKEN
================================================================================

1. Open Telegram, search @BotFather
2. Send: /newbot
3. Choose bot name: "Facebook Activity Tracker"
4. Choose username: "my_fb_tracker_bot_123" (must be unique)
5. COPY THE TOKEN (long string with numbers and letters)

================================================================================
STEP 3: DEPLOY TO RENDER
================================================================================

1. Go to https://render.com and sign up with GitHub
2. Click "New +" → "Web Service"
3. Connect your facebook-tracker-bot repository
4. Fill in:
   - Name: facebook-tracker-bot
   - Environment: Python 3
   - Build Command: pip install -r requirements.txt
   - Start Command: cd app && python main.py
   - Instance Type: Free

5. ADD THESE ENVIRONMENT VARIABLES:

   TELEGRAM_BOT_TOKEN = (paste your token from BotFather)
   FB_EMAIL = your_facebook_email@gmail.com
   FB_PASSWORD = your_facebook_password
   PORT = 10000

6. Click "Create Web Service"
7. Wait for build (2-3 minutes)
8. Check logs for: "✅ Flask server on 0.0.0.0:10000"

================================================================================
STEP 4: TEST YOUR BOT
================================================================================

1. Open Telegram
2. Find your bot (the username you created)
3. Send: /start
4. You should see a menu with options

5. In Telegram, send a Facebook profile URL:
   https://facebook.com/username
   
6. Bot will start tracking that profile

================================================================================
TELEGRAM COMMANDS REFERENCE
================================================================================

/start          - Show menu
/add URL        - Add Facebook profile URL
/list           - Show all tracked profiles
/status ID      - Check live status
/stop ID        - Stop tracking
/history ID     - View activity history
/help           - Show help

Example: /add https://facebook.com/username

================================================================================
COMMON ISSUES & FIXES
================================================================================

❌ "ModuleNotFoundError"
→ Make sure requirements.txt is in GitHub repo root

❌ Facebook login fails
→ Check email/password are correct
→ Disable 2FA temporarily
→ Approve login attempt email from Facebook

❌ Telegram bot not responding
→ Wait 30 seconds, try again
→ Check token is correct
→ Check Render logs for errors

❌ Service not starting
→ Check all Environment Variables are set correctly
→ Make sure file structure is correct
→ Check Render logs tab for error details
